
# Company Management & Data Analysis System

## Project Overview

The Company Management & Data Analysis System is a MySQL-based project developed to store, manage, and analyse employee information in an organisation.

The database contains 7 tables and 294 records. It helps manage employee details, departments, projects, attendance, salaries, and leave requests.

## Objectives

- Manage employee information efficiently.
- Maintain department and project details.
- Track employee attendance and leave requests.
- Store and analyse salary information.
- Generate meaningful business insights using SQL.

## Technologies Used

- MySQL
- SQL
- MySQL Workbench

## Database Structure

The project contains seven tables:

1. **Departments** – Stores department names and locations.
2. **Employees** – Stores employee details and salary information.
3. **Projects** – Stores project details, budgets, and dates.
4. **Employee_Project** – Maintains employee and project assignments.
5. **Attendance** – Stores employee attendance records.
6. **Salaries** – Maintains monthly salary details, bonuses, and deductions.
7. **Leave_Requests** – Stores employee leave applications and their status.

## How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open MySQL Workbench and connect to your database server.
3. Execute `01_create_database.sql`.
4. Execute `02_create_tables.sql`.
5. Execute `03_insert_data.sql`.
6. Execute the remaining SQL files in numerical order.
